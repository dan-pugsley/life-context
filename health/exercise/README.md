# Exercise

Training activities, programming, injury management, and fitness goals.

## Domain-specific structure

Below this domain node, structure is specific to exercise:

- `issues/` — ongoing physical issues and injury history (named subfolders with flat event files + optional assets/)
- `events/` — training milestones, assessments, and notable sessions
- `programming/` — periodised training programming (macrocycles → mesocycles → microcycles → workouts). See [programming/README.md](programming/README.md) for conventions
